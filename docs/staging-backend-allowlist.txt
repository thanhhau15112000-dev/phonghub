## Explicitly excluded from this snapshot

- .env and any secret-bearing file or value
- target/**, node_modules/**, and .wrangler/**
- package.json and package-lock.json (Worker/Cloudflare dependency scope)
- src/worker.ts, tsconfig.json, and wrangler.jsonc (known Worker typecheck blocker)
- log1.md (reserved for the separate documentation commit after the first push)
- README.md, context.md, and docs/api-spec.yaml (not part of this verified delta)
- Any path not listed above, including a frontend React tree if later created

This snapshot is a staging baseline only and is not release-ready.
